# Contributing

This repository does not accept external contributions.

- Issues and pull requests from anyone other than the repository owner are
  closed automatically (see `.github/workflows/lockdown.yml`).
- GitHub interaction limits are set to "collaborators only" on top of that.
- The source is published for reference only. See `LICENSE`.

If you believe you found a security problem, contact the owner directly via
the e-mail address on the GitHub profile instead of opening an issue.
